# agnostep
How to build a complete AGNoStep Desktop

With AGNoStep 3rd release, the AGNoStep project will be dispatched in several modules:
- agnostep-desktop (rel. 3 not yet published): the core Desktop. It will provide a choice between Classic and Modern features.
- agnostep-theme (rel. 3 not yet published): how theming the Desktop with native AGNOSTEP theme, but not only.
- agnostep-apps-manager: how to easily fetch, build and install apps of the GNUstep echosystem. It will be the new release of previous `AgnostepManager.app`.

This is a work in progress as I needed to rewrite many things... It is coming soon.
You will also find many improved things and new applications like Epeira Web Browser.
